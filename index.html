Copias y aplicación

Guardado en este celular

Las órdenes quedan en este navegador y funcionan sin internet cuando la aplicación indica que está lista. No hay sincronización automática con otros dispositivos.

Si se pierde el celular o se borran los datos del navegador, necesitarás una copia para recuperarlos.

La restauración pide confirmación antes de reemplazar las órdenes.

Instalar en Android

Abre el enlace con Chrome mientras tienes internet. En el menú ⋮ elige «Instalar aplicación» o «Añadir a pantalla de inicio».

Preparando uso sin conexión…

Antes de llevarla al taller, activa el modo avión, cierra y vuelve a abrir la aplicación para comprobarla en tu teléfono.
